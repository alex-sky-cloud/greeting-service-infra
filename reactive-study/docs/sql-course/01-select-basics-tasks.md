## Как сдавать задания

Для **каждого** задания пришлите в чат:

1. Текст SQL-запроса.
2. Кратко — сколько строк вернулось (или первые 2–3 строки результата).

Не обязательно скидывать все 5 000 строк — достаточно подтвердить, что результат логичен.

---

## Задание 1 — конкретные столбцы

Выберите **только** столбцы `id` и `email` для **всех** пользователей, но не более **5** строк.

**Подсказка:** нужны `SELECT`, `FROM`, `LIMIT`.

---

## Задание 2 — фильтр по id

Выберите `id`, `full_name` пользователя с **`id = 1`**.

Ожидаемый результат — **ровно 1 строка** (Ann Smith).

---

## Задание 3 — фильтр по email

Выберите `id`, `email`, `full_name` пользователя с email **`bob@example.com`**.

---

## Задание 4 — диапазон и сортировка

Выберите `id` и `full_name` пользователей с **`id` от 5 до 9 включительно**, отсортированных по `id` **по убыванию** (`DESC`).

Ожидается **5 строк**: id = 9, 8, 7, 6, 5.

---

## Задание 5 — топ по дате регистрации

Выберите `id`, `email`, `created_at` для **3 пользователей с самой поздней** (наиболее новой) датой регистрации.

**Подсказка:** `ORDER BY created_at DESC LIMIT 3`.

---

## Задание 6 — полный запрос

Составьте запрос, который:

- берёт данные из `users`;
- оставляет только пользователей с **`id > 100`**;
- возвращает столбцы **`id`** и **`email`**;
- сортирует по **`id`** по возрастанию;
- возвращает **не более 10** строк.

Пришлите запрос **и** количество строк в результате.

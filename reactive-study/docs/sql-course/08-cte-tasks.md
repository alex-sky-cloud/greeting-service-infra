# Тема 08 — Практические задания

> **Статус:** практика · **Проверка:** присылайте SQL в чат, ответ сверяется по базе
> **Контекст:** интернет-магазин **Reactive Shop**, база `reactive_study`.

В начале сессии:

```sql

SET search_path TO reactive_study;
```

Пришлите в чат **только SQL-запросы**. Результат проверяется по базе.

Заданий **16**. Можно сдавать блоками: сначала **1–3**, затем **4–7**, затем **8–10**, затем **11–16**.

Можно использовать материал тем **01–07**, если он нужен по смыслу задачи.

Задания **1–10** — на `WITH` и `WITH RECURSIVE`: сводка на промежуточном имени, сравнение строки с одним числом по всей таблице, подчинённые отделы на любой глубине, цепочка руководителей, путь по дереву, деньги и люди по дереву целиком.

Задания **11–16** — те же таблицы, но **без рекурсии**: один шаг по дереву через `JOIN` той же таблицы с собой. Это тоже типовые вопросы собеседований: сотрудник и его начальник, прямые подчинённые, листья дерева.

## Как читать таблицы

**`departments` — отделы компании**

| Столбец | Что в нём лежит |
|---|---|
| `id` | номер отдела |
| `parent_id` | номер отдела, которому этот отдел подчинён; пусто (`NULL`) значит, что это самый верхний отдел компании |
| `name` | название отдела |

**`employees` — сотрудники**

| Столбец | Что в нём лежит |
|---|---|
| `id` | номер сотрудника |
| `manager_id` | номер сотрудника, который является его начальником; пусто (`NULL`) значит, что начальника нет |
| `department_id` | номер отдела из `departments`, в котором сотрудник работает |
| `full_name` | имя и фамилия |
| `position` | должность |
| `salary` | зарплата в месяц |

**`catalog_sections` — разделы каталога товаров**

| Столбец | Что в нём лежит |
|---|---|
| `id` | номер раздела |
| `parent_id` | номер раздела, внутри которого находится этот раздел; пусто (`NULL`) значит, что это корневой раздел каталога |
| `name` | название раздела |

**Как связаны товары, разделы и заказы**

| Столбец | Что в нём лежит |
|---|---|
| `products.section_id` | номер раздела из `catalog_sections`, в котором лежит товар |
| `orders.product_id` | номер товара из `products`, который купили в этом заказе |
| `orders.amount` | сумма заказа в рублях |

В заданиях про деньги по каталогу берутся **все** заказы, независимо от статуса.

## Задание 1 — люди и деньги по каждому отделу

**Ситуация:** HR-директор просит справку по отделам компании.

- В таблице `employees` каждая строка — один сотрудник.
- В столбце `department_id` записано, в каком отделе он работает.
- В столбце `salary` записана его зарплата в месяц.
- Название отдела лежит в таблице `departments` в столбце `name`.
- В справке нужны три столбца.
  - Первый столбец — название отдела.
  - Второй столбец — сколько сотрудников работает в этом отделе.
  - Третий столбец — сумма зарплат сотрудников этого отдела.
- Считается только тот отдел, который записан у сотрудника в `department_id`. Подчинённые отделы в этом задании не учитываются.
- Отделы, в которых нет ни одного сотрудника, в справку не попадают.

## Задание 2 — отделы с фондом выше среднего

**Ситуация:** финансовый директор хочет увидеть отделы, которые забирают больше денег, чем отдел в среднем.

- Фонд отдела — это сумма зарплат сотрудников, у которых в `department_id` стоит номер этого отдела.
- Средний фонд считается по отделам, в которых есть хотя бы один сотрудник.
- В отчёте нужны два столбца.
  - Первый столбец — название отдела.
  - Второй столбец — фонд этого отдела.
- В отчёт попадают только те отделы, у которых фонд больше среднего фонда.

## Задание 3 — сотрудники с зарплатой выше средней

**Ситуация:** руководитель готовится к пересмотру зарплат и хочет список тех, кто получает больше среднего по компании.

- Средняя зарплата считается по всем 15 сотрудникам таблицы `employees`.
- В списке нужны два столбца.
  - Первый столбец — имя и фамилия сотрудника из `full_name`.
  - Второй столбец — его зарплата из `salary`.
- В список попадают сотрудники, у которых зарплата строго больше средней.
- Среднее не округляется: сравнение идёт с точным значением.

## Задание 4 — что входит в логистический департамент

**Ситуация:** новый руководитель логистики просит показать, какие отделы ему подчинены, включая отделы внутри отделов.

- Нужный отдел называется «Логистический департамент», его номер в `departments` — `3`.
- Отдел подчинён другому отделу, если в его `parent_id` стоит номер этого другого отдела.
- Подчинение может быть не прямым: отдел может быть внутри отдела, который внутри «Логистического департамента».
- В отчёте нужны три столбца.
  - Первый столбец — номер отдела.
  - Второй столбец — название отдела.
  - Третий столбец — уровень вложенности.
    - У самого «Логистического департамента» уровень равен `1`.
    - У отдела, который подчинён ему напрямую, уровень равен `2`.
    - У отдела, который подчинён отделу уровня `2`, уровень равен `3`.
- Сам «Логистический департамент» в отчёте тоже нужен.

- У генерального директора в `manager_id` пусто.
- В отчёте нужны три столбца.
  - Первый столбец — номер шага.
    - У самой Светланы Ким шаг равен `1`.
    - У её начальника шаг равен `2`.
    - У начальника её начальника шаг равен `3`, и так до самого верха.
  - Второй столбец — имя и фамилия из `full_name`.
  - Третий столбец — должность из `position`.
- Сама Светлана Ким в отчёте тоже нужна.

## Задание 6 — путь до каждого отдела

**Ситуация:** в корпоративном справочнике нужно печатать полное расположение отдела, а не только его название.

- Самый верхний отдел компании — тот, у которого `parent_id` пустой.
- В справочнике нужны три столбца.
  - Первый столбец — номер отдела.
  - Второй столбец — уровень вложенности, где у самого верхнего отдела уровень равен `1`.
  - Третий столбец — полное расположение отдела: названия всех отделов от самого верхнего до этого, через разделитель ` / `.
    - Для самого верхнего отдела в этом столбце стоит только его название: `Компания`.
    - Для «Склада», который подчинён «Логистическому департаменту», в этом столбце стоит `Компания / Логистический департамент / Склад`.
- В справочник попадают все отделы компании.

  - Второй столбец — сумма этих заказов из `orders.amount`, округлённая до двух знаков после запятой.

## Задание 16 — отделы без подчинённых отделов

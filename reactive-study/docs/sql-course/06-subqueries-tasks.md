# Тема 06 — Практические задания

> **Статус:** практика · **Предыдущий шаг:** интервью ✅
> **Контекст:** интернет-магазин **Reactive Shop**, база `reactive_study`.

В начале сессии:

```sql

SET search_path TO reactive_study;
```

Пришлите в чат **только SQL-запросы**. Результат проверяется по базе.

Заданий **13** плюс **5** дополнительных. Основную часть можно сдавать блоками: сначала **1–7**, затем **8–13**. Дополнительные **14–18** — отдельно, когда нужно закрепить отбор по отделу внутри подзапроса.

## Задание 1 — заказы дороже среднего

**Ситуация:** финансовый отдел считает крупной покупкой заказ, сумма которого выше средней суммы по всем заказам магазина.

Среднюю сумму никто заранее не сообщает — её надо получить из тех же данных.

**Что получить:** 10 строк.

- Поля:
  - номер заказа,
  - сумма заказа.

Сначала заказы с большей суммой.

---

## Задание 2 — самый дорогой заказ в истории

**Ситуация:** руководитель просит показать заказ на самую большую сумму за всё время работы магазина.

Наибольшая сумма заранее неизвестна.

**Что получить:** все заказы, сумма которых равна этой наибольшей.

- Поля:
  - номер заказа,
  - сумма заказа.

## Задание 3 — счётчик заказов в списке клиентов

**Ситуация:** в административной панели выводится список клиентов, и рядом с каждым нужно показать, сколько у него заказов.

Клиенты без покупок из списка не исчезают — у них в этой графе стоит ноль.

**Что получить:** 10 строк.

- Поля:
  - номер клиента,
  - имя клиента,
  - число заказов этого клиента.

Сортировать по номеру клиента, от меньшего к большему.

## Задание 11 — заказы выше личного среднего клиента

**Ситуация:** аналитик ищет покупки, которые для самого покупателя были нетипично крупными: сумма заказа выше средней суммы заказов **этого же** клиента.

Сравнение идёт с личным средним каждого клиента, а не со средним по магазину.

**Что получить:** 10 строк.

- Поля:
  - номер заказа,
  - номер клиента, которому принадлежит этот заказ,
  - сумма заказа.

Имени клиента, почты и других полей карточки в этом отчёте нет.

Сортировать по номеру заказа, от меньшего к большему.

- Поля:
  - название отдела.

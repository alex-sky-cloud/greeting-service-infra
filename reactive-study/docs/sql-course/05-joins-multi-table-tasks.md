## Задание 1 — карточка заказа 2

**Ситуация:** оператор поддержки открывает заказ с номером **2**.

**Что получить:** одна строка.

- Поля:
  - номер заказа,
  - имя клиента,
  - артикул товара,
  - название отдела,
  - сумма заказа.

## Задание 4 — число заказов по каждому отделу

**Ситуация:** нужен полный рейтинг отделов по числу заказов.

- Поля:

Сначала строки с большим числом заказов.

**Что получить:** по одной строке на каждый заказ этого клиента.

- Поля:

  - артикул товара,
  - название отдела,
  - сумма заказа.

## Задание 12 — два показателя по каждому отделу

**Ситуация:** по каждому отделу в отчёте нужны два числа.

Первое — сколько заказов отнесено к этому отделу.

Второе — у скольких из них в строке отчёта заполнено название отдела.

Продажи без отдела не исключать из отчёта.

**Что получить:** по одной строке на каждый отдел в отчёте.

- Поля:
  - название отдела,
  - число заказов,
  - число заказов с заполненным названием отдела.

Сначала строки с большим числом заказов.

  - название отдела.

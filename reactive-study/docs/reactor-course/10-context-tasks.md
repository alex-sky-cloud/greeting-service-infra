## Задача 1. Подпись заказа с номером трассировки

**Ситуация:**

В каждую строку журнала нужно добавить номер трассировки запроса.

Номер кладёт в контекст веб-фильтр, а метод его параметром не получает.

**Что сделать:**

`describe(int orderId)`.

**Ожидаемый результат:**

| Вызов | Контекст | Строка |
|---|---|---|
| `describe(7)` | `traceId=T-1` | `T-1 / заказ 7` |
| `describe(7)` | пустой | `без трассировки / заказ 7` |
| один и тот же `describe(3)` | `traceId=A` | `A / заказ 3` |
| тот же `describe(3)` | `traceId=B` | `B / заказ 3` |

## Задача 2. Передать цепочке пользователя

**Ситуация:**

Готовая цепочка где-то внутри читает из контекста `userId`.

Нужно передать ей пользователя, не теряя того, что уже положил в контекст вызывающий код.

**Что сделать:**

`withUser(Mono<String> chain, String userId)`.

**Ожидаемый результат:**

Пользователь `u-42`:

| Цепочка | Контекст вызывающего | Результат |
|---|---|---|
| `заказ 7` + `flatMap`, который читает `userId` | пустой | `заказ 7 открыл u-42` |
| читает `traceId` и `userId` | `traceId=T-5` | `T-5/u-42` |

## Задача 3. Строки заказов с номером трассировки

**Ситуация:**

Выгрузка заказов клиента для службы поддержки.

Каждая строка — с номером трассировки запроса, чтобы найти её в логах.

**Что сделать:**

`tracedOrderLines(int customerId)`.

1. Строки `<traceId>: заказ <id>` в порядке `id`.
2. Номера трассировки нет — вместо него `нет-трассы`.

**Ожидаемый результат:**

Клиент 3:

- с `traceId=T-9` — `T-9: заказ 7`, `T-9: заказ 8`, `T-9: заказ 9`;
- без `traceId` — `нет-трассы: заказ 7`, `нет-трассы: заказ 8`, `нет-трассы: заказ 9`.

## Задача 4. Котировка партнёра от имени партнёра

**Ситуация:**

Магазин запрашивает котировку у партнёра:

- партнёрский API должен видеть арендатора `partner`;
- итоговую строку нужно подписать арендатором вызывающего — его кладёт в контекст вызывающий код.

**Что сделать:**

`quoteLine()` — строка `<tenant вызывающего>: <котировка>`.

**Ожидаемый результат:**

Вызывающий подписался с `tenant=shop`. Результат — `shop: partner-quote for partner`.

## Задача 1. Крупные вручённые заказы

**Ситуация:**

Отдел качества обзванивает покупателей крупных доставленных заказов.

**Что сделать:**

`bigDeliveredOrderIds()` — номера заказов:

1. Статус `delivered`.
2. Сумма от 1000 включительно.
3. По возрастанию номера.

**Ожидаемый результат:**

1, 11, 12, 13, 17.

## Задача 2. Выручка по вручённым заказам

**Ситуация:**

Бухгалтерии нужна сумма всех заказов со статусом `delivered`.

**Что сделать:**

`deliveredRevenue()` — одно число.

**Ожидаемый результат:**

13119.00.

## Задача 3. Число заказов в каждом статусе

**Ситуация:**

Дашборд показывает, сколько заказов в каждом статусе.

**Что сделать:**

`countByStatus()` — карта «статус → число заказов».

**Ожидаемый результат:**

| Статус | Заказов |
|---|---|
| delivered | 10 |
| shipped | 3 |
| cancelled | 3 |
| paid | 2 |
| new | 2 |

## Задача 4. Первые три неотменённых заказа клиента

**Ситуация:**

В личном кабинете — блок «Последние заказы»:

- первые три заказа клиента по номеру;
- отменённые не показываются;
- остальные заказы клиента читать из базы не нужно.

**Что сделать:**

`firstThreeActiveOrderIds(int customerId)`.

**Ожидаемый результат:**

| Клиент | Номера |
|---|---|
| 1 | 1, 2, 3 |
| 5 | 12, 13, 14 |
| 7 | 17, 19 |
| 8 | пусто |

## Задача 5. Подпись клиента для шапки письма

**Ситуация:**

В шапке письма — имя и город клиента.

Письмо без клиента отправлять нельзя: вызывающий код должен получить понятную ошибку.

**Что сделать:**

`customerTitle(int customerId)`.

1. Строка `<имя> (<город>)`.
2. Клиента нет — ошибка `CourseExceptions.CustomerNotFoundException` (готовый класс, конструктор принимает номер клиента).

**Ожидаемый результат:**

| Клиент | Результат |
|---|---|
| 1 | `Анна Смирнова (Москва)` |
| 99 | ошибка `CustomerNotFoundException`, сообщение «Клиент 99 не найден» |

## Задача 6. Сумма всех заказов клиента

**Ситуация:**

В карточке клиента — сумма всех его заказов, включая отменённые.

У клиента без заказов в карточке должен стоять 0, а не пустое поле.

**Что сделать:**

`totalOfCustomer(int customerId)`.

**Ожидаемый результат:**

| Клиент | Сумма |
|---|---|
| 2 | 3010.00 |
| 8 | 0 |

## Задача 7. Города клиентов без повторов

**Ситуация:**

Фильтр «Город» на странице клиентов:

- каждый город — один раз;
- в порядке первого появления при просмотре клиентов по номеру.

**Что сделать:**

`citiesInOrderOfAppearance()`.

**Ожидаемый результат:**

Москва, Казань, Самара.

## Задача 1. Заказы клиентов города

**Ситуация:**

Региональный менеджер выгружает все заказы клиентов своего города.

Порядок не важен, важна скорость: заказы разных клиентов можно читать одновременно.

**Что сделать:**

`ordersOfCity(String city)` — все заказы всех клиентов города.

**Ожидаемый результат:**

Москва — заказы 1, 2, 3, 4, 10, 11, 17, 18, 19 в любом порядке.

---

## Задача 2. Заказы клиентов города блоками по клиентам

**Ситуация:**

Тот же отчёт, но для печати:

- заказы идут блоками по клиентам в порядке номера клиента;
- внутри блока — по возрастанию номера заказа.

**Что сделать:**

`ordersOfCityByCustomer(String city)`.

**Ожидаемый результат:**

Казань (клиенты 2, 5, 8) — заказы строго в порядке 5, 6, 20, 12, 13, 14, 15.

## Задача 3. Сроки доставки, не больше двух запросов одновременно

**Ситуация:**

Сервис сроков доставки принадлежит партнёру. По договору к нему можно обращаться не больше чем двумя запросами одновременно.

При этом по очереди — слишком долго.

**Что сделать:**

`deliveryLines(List<String> cities)` — строка `<город>: <дни> дн.` на каждый город.

1. Одновременно к сервису — не больше двух запросов.
2. Все четыре города (Москва, Казань, Самара, Новосибирск) — меньше чем за 700 мс. По очереди вышло бы 750 мс.
3. Порядок строк не важен.

**Ожидаемый результат:**

- строки `Москва: 1 дн.`, `Казань: 3 дн.`, `Самара: 2 дн.`, `Новосибирск: 6 дн.` в любом порядке;
- запросов в работе одновременно — ровно 2;
- вызовов сервиса — 4.

## Задача 4. Сроки доставки в порядке запроса

**Ситуация:**

Экран оформления заказа показывает сроки по городам из списка, строго в порядке списка.

Ограничения партнёра здесь нет — это внутренний сервис.

**Что сделать:**

`deliveryLinesInRequestOrder(List<String> cities)`.

1. Строки — в порядке списка городов, даже если ответ по позднему городу пришёл раньше.
2. Все запросы идут одновременно: четыре города — меньше чем за 550 мс.

**Ожидаемый результат:**

- строки `Москва: 1 дн.`, `Казань: 3 дн.`, `Самара: 2 дн.`, `Новосибирск: 6 дн.` — именно в этом порядке;
- одновременно в работе — 4 запроса.

## Задача 5. Сводка по клиенту одной строкой

**Ситуация:**

В шапке карточки клиента — одна строка: имя, число заказов и их сумма.

**Что сделать:**

`customerSummary(int customerId)`.

1. Строка `<имя>: заказов <N>, сумма <S>`. Сумма `S` — с двумя знаками после точки.
2. Клиент без заказов — строка с нулями.
3. Клиента нет — пустой ответ.

**Ожидаемый результат:**

| Клиент | Строка |
|---|---|
| 3 | `Вера Лаптева: заказов 3, сумма 6760.00` |
| 8 | `Зоя Белова: заказов 0, сумма 0.00` |
| 99 | пусто |

## Задача 6. Строки заказов клиента для печати

**Ситуация:**

Печать накладных: на каждый заказ клиента — строка с именем клиента, номером и суммой заказа.

**Что сделать:**

`orderLines(int customerId)`.

1. На каждый заказ — строка `<имя> — заказ <номер> — <сумма>`.
2. По возрастанию номера заказа.

**Ожидаемый результат:**

| Клиент | Строки |
|---|---|
| 7 | `Жанна Петрова — заказ 17 — 1999.00`, `Жанна Петрова — заказ 18 — 250.00`, `Жанна Петрова — заказ 19 — 3600.00` |
| 99 | пусто |

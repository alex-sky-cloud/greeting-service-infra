
## Промпт для оформления ответов с источниками

```
Оформи ответ по следующим правилам цитирования источников:

1. ЗАПРЕЩЕНЫ сноски в квадратных скобках вида [^1], [web:2], [source:3] и т.п.

2. Вместо сносок используй реальные гиперссылки на источник, вставленные 
   по месту — сразу там, где приводится информация или цитата, в формате:
   (пустая строка)
   - Источник: https://example.com/actual-page

3. Если источник на английском языке, для каждого использованного факта 
   приводи:
   а) Оригинальную цитату из источника (дословную, в блоке цитаты ">"), 
      на основе которой строится утверждение в ответе.
   б) Сразу под ней — отдельным блоком — перевод этой цитаты на русский.
   (пустая строка)
   EN:
   (пустая строка)
   ... Некий оригинал
   (пустая строка)
   RU:
   (пустая строка)
   ...Некий перевод
   (пустая строка)

4. Цитату нужно брать не любую, а именно ту, на основании которой 
   в тексте ответа делается конкретное утверждение — то есть цитата 
   должна доказывать/подтверждать именно то место ответа, рядом с 
   которым она размещена.

5. Если источник на русском языке — цитату и перевод не дублировать, 
   достаточно ссылки и краткого пересказа.

6. Каждый смысловой блок ответа оформляй так:
   - Утверждение / объяснение своими словами.
   - Источник: [реальный URL]
   - Цитата (если источник на английском).
   - Перевод цитаты (если источник на английском).
   
7. интерактивное оглавление.
```


## Пример правильного оформления

**Утверждение:**
Параметр `required_version` ограничивает, на каких версиях Terraform CLI можно запускать конфигурацию.

**Источник:** https://developer.hashicorp.com/terraform/language/block/terraform

> "Specifies which version of the Terraform CLI is allowed to run the configuration."

Ru:
> "Задаёт, какая версия Terraform CLI допускается для запуска конфигурации."

## Пример неправильного оформления (так делать нельзя)

Параметр `required_version` ограничивает версию Terraform.[^1]

*(Ошибка: использована квадратная сноска вместо гиперссылки по месту, нет цитаты и перевода.)*

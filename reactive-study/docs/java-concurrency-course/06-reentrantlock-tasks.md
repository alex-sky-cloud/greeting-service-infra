## Задача 1. Встречный перевод с отступлением

**Ситуация:**

Два счёта по 100. Встречный перевод по 10, как в теме 05. Нужно **завершиться**, не зависнуть.

**Что сделать:**

1. Два потока переводят одновременно.
2. Если второй замок не взять за короткое время — отпустить первый и повторить попытку.
3. Печать:

```text
left 100
right 100
готово
```

## Задача 2. Исключение не оставляет кабину закрытой

**Ситуация:**

Рабочий берёт замок, бросает исключение «сбой», затем второй поток должен **войти** в ту же критическую секцию и напечатать `вошёл`.

**Что сделать:**

1. Первый поток: захват, исключение, завершение потока.
2. Второй стартует сразу после старта первого (или вместе).
3. В выводе есть `вошёл`. Программа не висит.

## Задача 3. Окно: пусто и полно

**Ситуация:**

Буфер на **1** место. Производитель кладёт `1`, `2`, `3`. Потребитель забирает в том же порядке.

**Что сделать:**

1. Производитель не кладёт во занятое окно. Потребитель не берёт из пустого.
2. Две разные очереди ожидания на одном замке (кто ждёт место, кто ждёт товар).

**Ожидаемый результат:**

```text
1
2
3
```

## Задача 4. Не ждать вечно

**Ситуация:**

Касса занята одним потоком на **1000 мс**. Второй не должен стоять дольше **200 мс**: если не вошёл — печатает `занято` и заканчивает.

**Что сделать:**

```text
занято
```

Первый поток потом печатает `свободно`. Порядок: сначала `занято`, затем `свободно` (или `свободно` после паузы первого — главное, второй не ждёт всю секунду).

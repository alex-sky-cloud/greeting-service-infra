# Тема 13. Практика: CompletableFuture

> **Статус:** практика · **Как сдавать:** код в чат.

---

## Задача 1. Цена со скидкой

**Ситуация:**

Цена 200 приходит асинхронно. Потом из неё делают «минус 10%» синхронно. `main` печатает итог.

**Что сделать:**

```text
180
```

Процесс завершается.

---

## Задача 2. Карточка из двух сервисов

**Ситуация:**

Имя клиента грузится асинхронно (`Анна`), город — асинхронно (`Казань`). Карточка — одна строка `Анна, Казань` после **обоих**.

**Что сделать:** печать одной строки, без ручного «подождал один, потом второй» в `main` как единственной склейки (склеивает цепочка).

---

## Задача 3. Три склада

**Ситуация:**

Три асинхронных остатка: 10, 20, 30. Нужно дождаться всех и напечатать сумму **60**. Сам барьер всех трёх результата не содержит — сумму считают из трёх future.

---

## Задача 4. Склад недоступен

**Ситуация:**

Загрузка цены падает с `RuntimeException("нет прайса")`. Цепочка не должна уронить `main`: печатают запасную цену `0`.

**Ожидаемый результат:**

```text
0
```

---

## Задача 5. Свой пул

**Ситуация:**

Нужно увидеть, что продолжение после асинхронной стадии идёт **не** в `main` и в потоке **вашего** пула (имя потока содержит `shop-`).

**Что сделать:**

1. Стадия и продолжение с явным исполнителем.
2. Печать имени потока продолжения. В имени есть `shop-`.
3. Пул закрыт.

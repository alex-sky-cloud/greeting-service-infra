## Ревью

### Р1. Два метода

```java
synchronized void leftRight(B b) { b.right(); }
synchronized void right() {}
```

Поток 1: `a.leftRight(b)`. Поток 2: `b.leftRight(a)`. Почему возможен deadlock?

### Р2. Чем не deadlock

Поток крутит цикл и каждый раз меняет решение, глядя на другого. Состояние `RUNNABLE`. Почему это не deadlock?

### Р3. Дамп

В дампе: `waiting to lock <0xA>` и `locked <0xB>` у одного потока; у второго наоборот. Что это и как чинить по смыслу?

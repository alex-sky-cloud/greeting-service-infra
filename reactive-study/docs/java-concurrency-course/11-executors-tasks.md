# Тема 11. Практика: пул потоков

> **Статус:** практика · **Как сдавать:** код в чат.

---

## Задача 1. Сумма в фоне

**Ситуация:**

Нужно сложить 10 + 20 в рабочем потоке пула и забрать число в `main`.

**Что сделать:**

1. Пул из 1 потока.
2. `main` печатает `30` из результата задачи.
3. Пул остановлен, процесс сам завершается.

---

## Задача 2. Ошибка не пропала

**Ситуация:**

Задача в пуле бросает `IllegalStateException("нет склада")`. Нужно напечатать текст причины в `main`, не потерять её.

**Что сделать:**

```text
нет склада
```

Пул остановлен.

---

## Задача 3. Три отчёта, два работника

**Ситуация:**

Три отчёта по **200 мс**. Пул из **двух** рабочих. Все три должны закончиться, время ближе к 400 мс, не к 600.

**Что сделать:**

1. Печать `готово` после всех трёх.
2. Время программы меньше 550 мс.
3. Пул закрыт.

---

## Задача 4. Очередь без потолка потоков

**Ситуация:**

Пул: core 2, maximum 10, очередь **без ёмкости**. Подаёте 8 мгновенных задач.

**Что сделать:**

1. После выполнения напечатать, сколько потоков пул **когда-либо** создал (или сколько сейчас после прогрева). Ожидается **2**, не 8 и не 10.
2. Короткий комментарий в `main`: почему maximum не вырос.
3. Пул закрыт.

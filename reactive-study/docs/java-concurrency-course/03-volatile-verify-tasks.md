## Ревью

### Р1. Вечный цикл

```java
boolean stop;
// поток: while (!stop) {}
// main: stop = true;
```

Почему на собеседовании скажут, что цикл **может не остановиться**? Меняет ли дело `Thread.sleep(1)` внутри цикла по гарантии языка?

### Р2. volatile и ++

```java
volatile int n;
// два потока: по 100_000 раз n++;
```

Будет ли итог всегда 200000? Что именно даёт `volatile` в этом коде и чего не даёт?

### Р3. Порядок записей

Поток A: пишет `data = 42`, затем `ready = true` (`ready` — `volatile`, `data` — обычное `int`). Поток B: крутится, пока `!ready`, затем читает `data`.

Какое значение `data` обязан увидеть B? Почему обычного поля `ready` здесь мало?

## Самостоятельное выполнение

### С1. Сигнал смены

**Ситуация:** ночной поток печатает `ночь` в цикле, пока нет сигнала утра. Основная программа через **100 мс** даёт сигнал. Ночной поток печатает `утро` и заканчивается.

**Что сделать:** процесс завершается сам, в выводе есть `утро`, нет зависания.

### С2. Флага мало

**Ситуация:** два потока увеличивают одно поле по **30 000**. Поле объявлено так, чтобы изменения были **видны**. Итог всё равно должен быть **60000**.

**Что сделать:** основная программа печатает `60000`.

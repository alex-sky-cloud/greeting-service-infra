## Ревью

Код **не пишете**.

### Р1. Какой замок у какого метода?

Типовой вопрос: *на каком объекте стоит монитор у instance / static / блока?*

```java
class Desk {
    synchronized void a() {}
    static synchronized void b() {}
    void c() {
        synchronized (Desk.class) {}
    }
    void d() {
        synchronized (this) {}
    }
}
```

Для `a`, `b`, `c`, `d` назовите **объект**, чей монитор захватывается. Какие пары **мешают** друг другу, а какие — нет?

### Р2. Два объекта, одно поле

Типовой вопрос: *заблокируются ли два потока на разных экземплярах?*

```java
class Box {
    static int n;
    synchronized void add() { n++; }
}

Box x = new Box();
Box y = new Box();
// поток 1: x.add() в цикле 100_000 раз
// поток 2: y.add() в цикле 100_000 раз
```

1. Будут ли потоки ждать друг друга?
2. Чему **гарантированно** равен `n` после обоих циклов? Почему?

### Р3. Чтение без замка

Типовой вопрос: *достаточно ли синхронизировать только запись?*

```java
class Wallet {
    private int money;
    public synchronized void add(int v) { money += v; }
    public int get() { return money; }
}
```

Почему на собеседовании скажут, что `get()` написан неверно, если его вызывают из другого потока, пока идёт `add`?

## Самостоятельное выполнение

Класс с `main`, с нуля. Сюжеты те же, что на интервью, но **новая постановка**.

### С1. Точный итог двух окон

На собеседовании часто просят: *покажите гонку на счётчике и почините её*.

**Ситуация:** два окна выдачи увеличивают один талон по **25 000** раз каждое.

**Что сделать:**

1. Итог печатает основная программа после обоих окон.
2. В выводе ровно `50000` при каждом запуске.

```text
50000
```

### С2. Два стола, общий склад

Типовой вопрос: *instance synchronized не закрывает static*.

**Ситуация:** два стола упаковки (`table1`, `table2`). Оба списывают коробки с **одного** склада класса. Каждый стол — **10 000** списаний.

**Что сделать:**

1. Склад — одно общее поле на класс.
2. Вызовы идут через **разные** объекты столов.
3. Остаток склада после работы — **−20000** от начального 0, то есть итог списаний **20000**. Печатается число списаний.

```text
20000
```

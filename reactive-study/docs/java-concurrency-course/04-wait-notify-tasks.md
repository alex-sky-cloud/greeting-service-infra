## Задача 1. Пауза с ключом в руке

**Ситуация:**

Кассир зашёл в кабинку и **спит 800 мс**, не отдавая ключ. Помощник в это время не должен попасть в ту же кабинку.

**Что сделать:**

1. Поток кассира захватывает общий объект-кабину, затем пауза 800 мс **внутри** этой секции, печатает `кассир вышел`.
2. Поток помощника пытается зайти в ту же кабину и печатает `помощник внутри` только когда вошёл.
3. Строка помощника появляется **после** `кассир вышел`.

**Ожидаемый результат:**

```text
кассир вышел
помощник внутри
```

## Задача 2. Одна посылка

**Ситуация:**

Курьер кладёт одну посылку «книга» на стол. Получатель забирает её. Получатель не читает стол, пока посылки нет. Курьер не кладёт вторую, пока первую не забрали (здесь вторая не нужна — достаточно одной передачи).

**Что сделать:**

1. Получатель стартует первым и ждёт посылку.
2. Через **200 мс** курьер кладёт `книга` и заканчивает.
3. Получатель печатает `получил: книга`. Слово `книга` берётся со стола, не из константы печати получателя.

**Ожидаемый результат:**

```text
получил: книга
```

Программа завершается сама.

## Задача 3. Два покупателя, одна буханка

**Ситуация:**

Два покупателя ждут хлеб. Пекарь кладёт **одну** буханку. Забрать должен **только один**. Второй продолжает ждать следующую. Пекарь затем кладёт вторую.

**Что сделать:**

1. Два потока-покупателя, один пекарь.
2. Каждая буханка уходит ровно одному покупателю.
3. В выводе две строки `взял: белый` и `взял: ржаной` (порядок любой). Повторов одной буханки нет.

**Ожидаемый результат:**

```text
взял: белый
взял: ржаной
```

## Задача 4. Окно выдачи на три талона

**Ситуация:**

Окно вмещает **не больше одного** талона. Оператор выдаёт талоны `A`, `B`, `C`. Клиент забирает по одному. Оператор не кладёт следующий, пока окно занято.

**Что сделать:**

1. Клиент печатает талоны в порядке получения: `A`, затем `B`, затем `C`.
2. Программа завершается после третьего.

**Ожидаемый результат:**

```text
A
B
C
```

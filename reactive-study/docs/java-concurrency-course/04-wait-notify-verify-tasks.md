## Самостоятельное выполнение

### С1. Сигнал «можно»

**Ситуация:** рабочий ждёт разрешения. Основная программа через **150 мс** даёт разрешение. Рабочий печатает `пошёл`.

**Что сделать:** нет активного кручения без ожидания на мониторе; процесс завершается.

### С2. Стол на одну вещь

**Ситуация:** отправитель кладёт `ок`, получатель забирает и печатает `ок`. Получатель не читает пустой стол.

## Задача 1. Кнопка «Стоп» на конвейере

**Ситуация:**

Лента крутится в отдельном потоке без пауз внутри цикла. Через **200 мс** оператор нажимает «Стоп». Лента должна остановиться сама и напечатать, сколько циклов успела.

**Что сделать:**

1. Рабочий поток крутит пустой цикл, пока нет сигнала стоп, и считает обороты.
2. Основная программа через 200 мс даёт сигнал и **ждёт**, пока лента остановится.
3. Рабочий печатает `обороты: N` (N > 0). Основная печатает `лента остановлена`.
4. Процесс сам заканчивается меньше чем за **1000 мс**. Принудительно убивать поток нельзя.

**Ожидаемый результат:**

```text
обороты: 1847291
лента остановлена
```

Число оборотов любое больше нуля. Обе строки есть, процесс завершается.

## Задача 2. Счётчик на табло

**Ситуация:**

Два окна увеличивают одно табло по **80 000**. Табло должно быть **видно** всем, но одно только «видеть» мало: итог обязан быть точным.

**Что сделать:**

1. Два потока одновременно увеличивают одно поле.
2. После обоих итог **160000** при каждом запуске.
3. Основная программа печатает одно число.

**Ожидаемый результат:**

```text
160000
```

Если оставить только видимость поля без взаимного исключения, число будет меньше.

## Задача 3. Готово — можно читать сумму

**Ситуация:**

Сборщик считает сумму трёх цен: 10, 20, 30 — в своём потоке. Кассир **не должен** печатать сумму, пока сборщик не закончил раскладку. Связь — флаг «готово», не ожидание потока как единственная защита данных (поток кассира крутится, пока флаг ложный).

**Что сделать:**

1. Сборщик записывает сумму **60** в общее поле, затем ставит флаг готовности.
2. Кассир (основная программа) крутится, пока флаг не станет истинным, затем печатает сумму.
3. В выводе ровно `60`. Число 60 в печать кассира не зашивать заранее как константу вывода без чтения поля.

**Ожидаемый результат:**

```text
60
```

## Задача 4. Большое число на двух листочках

**Ситуация:**

Писатель 1000 раз записывает в общее поле `long` значение `0xFFFF_FFFF_0000_0001L`. Читатель 1000 раз читает это поле. Нужно, чтобы читатель **никогда** не увидел «склейку» двух разных записей: только 0 (старт) или это число целиком.

**Что сделать:**

1. Писатель и читатель — два потока, работают одновременно.
2. Если читатель увидел значение, которое не 0 и не указанная константа — печатает `повреждено` и заканчивает.
3. Если повреждений нет — основная программа после обоих потоков печатает `целые`.

**Ожидаемый результат:**

```text
целые
```

Строки `повреждено` нет.

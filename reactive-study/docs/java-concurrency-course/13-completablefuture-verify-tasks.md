### Р2. allOf и ошибка

Один из трёх future упал. Что будет с `allOf(...).join()`?

### Р3. Async без пула

Где по умолчанию крутится `thenApplyAsync(fn)` без второго аргумента? Почему туда не кладут HTTP-вызов?

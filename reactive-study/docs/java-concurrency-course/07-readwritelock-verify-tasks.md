## Ревью

### Р1. Два читателя и писатель

Могут ли два потока держать чтение сразу? Может ли в этот момент войти писатель?

### Р2. validate

Зачем вызывать `validate` после чтения полей при оптимистичном режиме? Что будет, если не вызвать?

### Р3. Реентерабельность

Поток взял `StampedLock` на запись и из того же потока снова берёт запись. Чем это опасно?

---

## Самостоятельное выполнение

### С1. Два чтения одного поля

Два потока читают справочник `ok → 1` одновременно, каждый по 50 раз. Писателя нет. Оба заканчивают, печатают `готово`.

### С2. Пара координат

Писатель ставит `(5, 5)`. Читатель печатает сумму только если оба поля из одной записи. Итог `10`.

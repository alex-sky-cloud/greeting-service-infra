## Задача 1. Частоты слов

**Ситуация:**

Два потока разбирают два списка слов. Нужна общая таблица «слово → сколько раз». Слова: поток A — `склад`, `касса`, `склад`. Поток B — `касса`, `двор`, `касса`.

**Что сделать:**

1. Оба пишут в одну таблицу одновременно.
2. После обоих печать в любом порядке, но частоты:

| слово | число |
|---|---|
| склад | 2 |
| касса | 3 |
| двор | 1 |

Увеличение счётчика по ключу — одна составная операция, не «достал / положил» двумя шагами.

## Задача 2. Список по городу

**Ситуация:**

Заказы раскладывают по городам. Два потока одновременно добавляют: A — Москва заказ 1 и 2; B — Москва заказ 3 и Казань заказ 4. У Москвы не должно потеряться ни одного заказа.

**Что сделать:**

1. Если списка города ещё нет — создать и добавить заказ **так, чтобы два потока не создали два разных списка**.
2. Печать размеров: `Москва 3`, `Казань 1`.

---

## Задача 3. Подписчики витрины

**Ситуация:**

Витрина почти всегда читает список имён подписчиков, редко добавляет. Два читателя 100 раз читают весь список, пока третий **один раз** добавляет `Новый`.

**Что сделать:**

1. Читатели не получают исключение модификации.
2. Программа завершается, печатает `обход ок`.
3. После добавления размер списка на 1 больше начального (старт: `Анна`, `Борис`).

Это единственный официальный публичный список локаций, который удалось найти — точной таблицы с "техническими" короткими кодами локаций (в нижнем регистре, для подстановки в Terraform) отдельно на сайте нет, кроме `am2`, который явно фигурирует в официальном примере провайдера.

## Ответ на вопрос о правильности `location = "am2"`

Да, значение `"am2"` подтверждено как реальное и рабочее — это буквально код амстердамского дата-центра в официальном обучающем примере провайдера Terraform.

Источник: https://serverspace.io/support/help/automation-terraform/

> "Server in Amsterdam called "server-1" with Ubuntu 20.04 operating system... location = "am2""

Перевод:
> "Сервер в Амстердаме под именем "server-1" с операционной системой Ubuntu 20.04... location = "am2""

## Проверка каждого свойства `terraform.tfvars.example` по документации Serverspace

Источник: https://serverspace.io/support/help/automation-terraform/

> "resource "serverspace_server" "server1" { image = "Ubuntu-20.04-X64" name = "server-1" location = "am2" cpu = 2 ram = 2048 boot_volume_size = 40*1024 ..."

Перевод:
> "Ресурс "serverspace_server" "server1" с параметрами: образ "Ubuntu-20.04-X64", имя "server-1", локация "am2", 2 vCPU, 2048 МБ RAM, объём загрузочного тома 40*1024..."


| Свойство в файле | Значение в файле | Подтверждено официальным примером | Комментарий |
| :-- | :-- | :-- | :-- |
| `api_key` | `"your_serverspace_api_key"` | Да, как имя параметра | В официальном примере переменная называется `s2_token`, а параметр провайдера — `key = var.s2_token`. Само значение — заглушка, реальный ключ выдаётся только в панели управления |
| `ssh_public_key` | `"ssh-ed25519 AAAA... ваш_публичный_ключ"` | Да, по структуре | Официальный пример использует ключ `ssh-rsa`, а не `ssh-ed25519`: `public_key = "ssh-rsa AAAAB3Nza...JUDjlM= root@CentOS.local"`. Тип ключа (rsa/ed25519) не принципиален для Serverspace, важен только сам публичный ключ целиком |
| `location` | `"am2"` | Да, дословно | Подтверждено выше цитатой |
| `image_family` | `"Ubuntu-20.04-X64"` | Да, дословно | Точное совпадение с `image = "Ubuntu-20.04-X64"` в примере |
| `control_plane_cpu`, `apps_cpu`, `postgres_cpu`, `gitlab_cpu` | `2`, `2`, `2`, `4` | Формат подтверждён | В примере `cpu = 2` и `cpu = 4` — те же типовые значения, конкретные числа зависят от задачи, а не жёстко заданы Serverspace |
| `control_plane_ram`, `apps_ram`, `postgres_ram`, `gitlab_ram` | `4096`, `8192`, `8192`, `8192` | Формат подтверждён | В примере `ram = 2048` и `ram = 8192` — RAM задаётся числом в мегабайтах, что подтверждает вашу схему |
| `control_plane_disk`, `apps_disk`, `postgres_disk`, `gitlab_disk` | `60`, `80`, `120`, `120` | Формат подтверждён | В примере `boot_volume_size = 40*1024` — диск в ГБ умножается на 1024 для перевода в МБ, именно так и сделано в вашем `main.tf` |
| `*_name` (все пять) | `"k8s-control-plane-1"` и т.д. | Формат подтверждён | В примере `name = "server-1"` — просто произвольная строка-имя, никаких требований Serverspace к шаблону имени нет |

Важное отличие от документации, которое нужно зафиксировать: официальный пример использует `ssh-rsa`, а не `ssh-ed25519` — оба формата валидны для SSH в целом, но именно в примере Serverspace показан `ssh-rsa`.

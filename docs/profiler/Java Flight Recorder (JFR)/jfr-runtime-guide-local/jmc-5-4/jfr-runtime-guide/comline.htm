A Справочник команд

Примечание:

Для использования Java Flight Recorder в производственной среде требуется коммерческая лицензия. Подробнее о коммерческих функциях и о том, как их включить, см. по адресу http://www.oracle.com/technetwork/java/javaseproducts/.

Это приложение служит кратким справочником команд, которые можно использовать с JFR (Java Flight Recorder, журнал полёта Java). Оно содержит следующие разделы:

  • раздел A.1, «Параметры командной строки»

  • раздел A.2, «Справочник диагностических команд»

A.1 Параметры командной строки

При запуске приложения Java командой java можно указать параметры, включающие Java Flight Recorder, задающие его настройки и начинающие запись (recording). Следующие параметры командной строки относятся к Java Flight Recorder:

  • -XX:+|-FlightRecorder

  • -XX:FlightRecorderOptions

  • -XX:StartFlightRecording

Эти параметры командной строки доступны только в коммерческой лицензии JDK (Java Development Kit, комплект разработки Java). Чтобы использовать их, необходимо также указать параметр -XX:+UnlockCommercialFeatures.

Примечание:

Параметры -XX следует использовать, только если вы хорошо понимаете устройство своей системы. Неправильное применение этих команд может повлиять на стабильность или производительность системы. Параметры -XX являются экспериментальными и могут быть изменены в любой момент.

A.2 Справочник диагностических команд

Ниже описываются диагностические команды (diagnostic commands), доступные для управления Java Flight Recorder, и параметры каждой команды. Эти сведения также можно получить, выполнив команду jcmd с указанным идентификатором процесса, затем параметром help и именем команды. Например, чтобы получить справку по команде JFR.start для выполняющегося процесса JVM (Java Virtual Machine, виртуальная машина Java) с идентификатором 5361, выполните следующее:

jcmd 5361 help JFR.start

Чтобы получить полный список диагностических команд, доступных JVM, не указывайте имя команды.

Диагностические команды, связанные с Java Flight Recorder:

  • JFR.start

  • JFR.check

  • JFR.stop

  • JFR.dump

Содержание

Предисловие

В этом документе описывается реализация среды выполнения JFR (Java Flight Recorder, журнал полёта Java) и приводятся инструкции по использованию средства.

Примечание:

Для использования Java Flight Recorder в производственной среде требуется коммерческая лицензия. Подробнее о коммерческих функциях и о том, как их включить, см. на странице http://www.oracle.com/technetwork/java/javaseproducts/.

Целевая аудитория

Этот документ предназначен для разработчиков Java и инженеров поддержки, которым нужно введение в архитектуру и реализацию среды выполнения Java Flight Recorder. Предполагается, что читатель имеет базовые знания языка программирования Java.

Специальные возможности документации

Сведения об обязательствах Oracle в области специальных возможностей см. на веб-сайте программы Oracle Accessibility Program по адресу http://www.oracle.com/pls/topic/lookup?ctx=acc&id=docacc.

Доступ к службе поддержки Oracle

Заказчики Oracle, которые приобрели поддержку, имеют доступ к электронной поддержке через My Oracle Support. Сведения см. по адресу http://www.oracle.com/pls/topic/lookup?ctx=acc&id=info либо по адресу http://www.oracle.com/pls/topic/lookup?ctx=acc&id=trs, если у вас нарушения слуха.

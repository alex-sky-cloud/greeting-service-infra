Получите исходный код клиентом SVN следующей командой.
svn checkout https://svn.java.net/svn/visualvm~svn/branches/release138

Есть два комплекта (suite):

  • visualvm: определяет основное приложение, и
  • plugins: содержит плагины, доступные в VisualVM Plugin Center (центре плагинов VisualVM).

Структура в SVN для выпуска VisualVM 1.3.8:

  • release138
    • visualvm  <--- комплект основного приложения
    • plugins    <--- для центра плагинов (jconsole, mbeans, glassfish)

Чтобы собрать основное приложение visualvm, нужны двоичные файлы платформы и профилировщика NetBeans 8.0, доступные здесь. Эти двоичные файлы нужно распаковать в каталог release138/visualvm. Для сборки или запуска VisualVM можно использовать ant run или ant build-zip.

Чтобы собрать комплект плагинов, используйте ant build или ant run. Это автоматически соберёт zip-дистрибутив основного приложения visualvm в release138/visualvm/dist/visualvm.zip и распакует его в каталог release138/plugins/visualvm. После этого сборка комплекта плагинов продолжается и собирает каждый отдельный плагин.

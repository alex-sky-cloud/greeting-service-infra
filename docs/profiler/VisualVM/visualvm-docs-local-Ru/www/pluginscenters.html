Центры плагинов

В этом документе собрано содержимое Plugins Centers (центров плагинов) всех выпущенных версий VisualVM и Java VisualVM. Плагины (plugin) можно скачать как файлы .nbm и установить в VisualVM вручную через Tools (Инструменты) | Plugins (плагины) | Downloaded (Загруженные). Чтобы получить файл плагина, нажмите ссылку дескриптора Plugin Center для вашей версии VisualVM и выберите нужный плагин. Может понадобиться скачать дополнительные плагины, чтобы удовлетворить зависимости выбранного плагина.

Обратите внимание: скачивать плагины с этой страницы и устанавливать их вручную стоит только если возникают проблемы с установкой через встроенный Plugin Center, например из-за сети (нет интернета, ограничения прокси и т. д.). Если сетевых проблем нет, используйте Tools (Инструменты) | Plugins (плагины) | Available Plugins (Доступные плагины), чтобы установить плагины прямо из программы.

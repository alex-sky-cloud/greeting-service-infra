Примечания к выпуску VisualVM 1.3.3

VisualVM — визуальный инструмент, объединяющий несколько командных утилит JDK и лёгкие возможности профилирования. Предназначен как для производственной среды, так и для разработки; он расширяет возможности мониторинга и анализа производительности платформы Java SE.

Выпуск VisualVM 1.3.3 основан на VisualVM 1.3.2. Список изменений и исправлений с момента VisualVM 1.3.2 см. в разделе Изменения в 1.3.3. Подробный обзор всех выпусков VisualVM и Java VisualVM см. на странице Обзор выпусков.

Системные требования

Поддерживаемые ОС:

  • Microsoft Windows (7, Vista, XP, Server): 32bit & 64bit
  • Linux: платформа Intel, 32bit & 64bit
  • Sun Solaris: платформы Intel и Sparc, 32bit & 64bit
  • Mac OS X: платформа Intel, 32bit & 64bit
  • HP-UX 11i: платформа PA-RISC, 32bit & 64bit

Требуемое ПО:

  • Oracle/Sun JDK 6+
  • OpenJDK 6+
  • IcedTea 6+
  • Apple JDK 6+
  • HP-UX JDK 6.0.01+

Изменения в 1.3.3

Возможности и улучшения:

  • Eclipse VisualVM Launcher теперь поддерживает Eclipse IDE 3.6 и новее.
  • Issue 337: Поддержка JUnit для Eclipse VisualVM Launcher
  • Issue 443: Автоматический детектор взаимных блокировок
  • Issue 452: Добавлена поддержка отслеживания суммарных байтов кучи Java, выделенных по потокам
  • Issue 455: Добавлен пробник «Pending Finalizers Count»
  • Issue 463: Добавлена поддержка отслеживания времени CPU по потокам
  • NetBeans issue 191779: Обнаруживать дамп кучи, вызванный OOME, и указывать, какой поток выбрасывает OOME
  • Сборка на NetBeans Platform и профилировщике 7.0.1

Исправленные ошибки:

  • Issue 416: VisualVM не запускается в Windows
  • Issue 419: Код Swing/AWT вызывается вне EDT
  • Issue 442: Поля в настройках прокси не обрезаются
  • Issue 446: Отсутствует информация о Perm Gen
  • Issue 454: Установка плагина Kill Application истекает по тайм-ауту во 2-й и последующих сессиях
  • Issue 460: NetBeans 7.0 распознаётся как 6.9+
  • Issue 462: Открытые ссылки на все файлы > 1 МБ после загрузки дампа кучи
  • Issue 465: Плагин VisualVM для Eclipse не может запустить VisualVM с JDK 1.7.0
  • Issue 466: Файлы libprofilerinterface.so на Solaris и Linux не исполняемые
  • запросом Issue Tracker со списком всех изменений в профилировщике NetBeans

Известные проблемы

  • Issue 224: Не удаётся профилировать память JBoss AS 4.2.3.GA
  • Issue 148: VisualVM зависает при потере удалённого соединения
  • Issue 120: Источник данных приложения JMX нельзя повторно использовать после перезапуска приложения
  • Issue 72: Запущенное приложение иногда не распознаётся

Предупреждение: из-за ошибки JDK снятие дампа кучи может аварийно завершить целевую JVM, если она работает на JDK 6 Update 16+ со сборщиком мусора Concurrent Mark Sweep (CMS). Обходной путь — использовать другой GC (например, -XX:+UseParallelGC). Похожая проблема, судя по всему, затрагивает и devbuilds JDK 7.

Чтобы просмотреть все известные проблемы, воспользуйтесь этим запросом Issue Tracker.

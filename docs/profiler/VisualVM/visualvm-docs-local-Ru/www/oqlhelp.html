Анализ Heap Dump (дамп кучи) с помощью Object Query Language (OQL)

OQL (Object Query Language, язык запросов к объектам) — язык запросов, похожий на SQL, для запросов к куче Java. OQL позволяет фильтровать и выбирать нужные сведения из кучи Java. Предопределённые запросы вроде "show all instances of class X" уже поддерживаются VisualVM, а OQL даёт больше гибкости. OQL основан на языке выражений JavaScript.

Запрос OQL имеет следующий вид: 


         select <JavaScript expression to select>
         [ from [instanceof] <class name> <identifier>
         [ where <JavaScript boolean expression to filter> ] ]

где имя класса — полное имя класса Java (пример: java.net.URL) или имя класса массива. char[] (или [C) — имя массива char, java.io.File (или [Ljava.io.File;) — имя java.io.File[] и так далее. Учтите, что полное имя класса не всегда однозначно идентифицирует класс Java во время выполнения. Может быть больше одного класса Java с одним и тем же именем, но загруженных разными загрузчиками. Поэтому имя класса может быть строковым id объекта класса. Если использовано ключевое слово instanceof, выбираются объекты подтипов. Если это ключевое слово не указано, выбираются только экземпляры точно указанного класса. Оба предложения from и where необязательны.

В предложениях select и (необязательном) where используется выражение на языке выражений JavaScript. Объекты кучи Java обёрнуты удобными объектами сценария, чтобы к полям можно было обращаться естественным синтаксисом. Например, к полям Java можно обращаться синтаксисом obj.field_name, а к элементам массива — синтаксисом array[index]. Каждый выбранный объект Java привязывается к переменной JavaScript с именем идентификатора, указанным в предложении from.

Примеры OQL

  • выбрать все String длины 100 или больше 
    
    select s from java.lang.String s where s.count >= 100
  • выбрать все массивы int длины 256 или больше 
    
    select a from int[] a where a.length >= 256
  • показать содержимое String, которые соответствуют регулярному выражению 
    
    select {instance: s, content: s.toString()} from java.lang.String s
    where /java/.test(s.toString())
  • показать значение path всех объектов File 
    
    select file.path.toString() from java.io.File file
  • показать имена всех классов ClassLoader 
    
    select classof(cl).name 
    from instanceof java.lang.ClassLoader cl
  • показать экземпляры Class, идентифицированного данной строкой id 
    
    select o from instanceof 0xd404b198 o
    Учтите, что 0xd404b198 — id класса (в сеансе). Его находят, глядя на id, показанный на странице этого класса.

Встроенные объекты и функции OQL

объект heap

Встроенный объект heap поддерживает следующие методы:

  • heap.forEachClass — вызывает функцию обратного вызова для каждого класса Java 
    
    heap.forEachClass(callback);
  • heap.forEachObject — вызывает функцию обратного вызова для каждого объекта Java 
    
    heap.forEachObject(callback, clazz, includeSubtypes);
    clazz — класс, экземпляры которого выбираются. Если не указан, по умолчанию java.lang.Object. includeSubtypes — логический флаг, который указывает, включать ли экземпляры подтипов. Значение по умолчанию этого флага — true.
  • heap.findClass — находит класс Java с данным именем 
    
    heap.findClass(className);
    где className — имя класса, который нужно найти. У результирующего объекта Class есть следующие свойства:
    • name — имя класса.
    • superclass — объект Class для суперкласса (или null, если java.lang.Object).
    • statics — пары имя, значение для статических полей класса.
    • fields — массив объектов полей. У объекта поля есть свойства name, signature.
    • loader — объект ClassLoader, который загрузил этот класс.

    У объектов Class есть следующие методы:

    • isSubclassOf — проверяет, является ли данный класс прямым или косвенным подклассом этого класса.
    • isSuperclassOf — проверяет, является ли данный Class прямым или косвенным суперклассом этого класса.
    • subclasses — возвращает массив прямых и косвенных подклассов.
    • superclasses — возвращает массив прямых и косвенных суперклассов.
  • heap.findObject — находит объект по данному id объекта 
    
    heap.findObject(stringIdOfObject);
  • heap.classes — возвращает перечисление всех классов Java
  • heap.objects — возвращает перечисление объектов Java 
    
    heap.objects(clazz, [includeSubtypes], [filter])
    clazz — класс, экземпляры которого выбираются. Если не указан, по умолчанию java.lang.Object. includeSubtypes — логический флаг, который указывает, включать ли экземпляры подтипов. Значение по умолчанию этого флага — true. Этот метод принимает необязательное выражение фильтра, чтобы отфильтровать результирующий набор объектов.
  • heap.finalizables — возвращает перечисление объектов Java, которые ожидают финализации.
  • heap.livepaths — возвращает массив путей, по которым данный объект жив. Этот метод принимает необязательный второй параметр — логический флаг. Этот флаг указывает, включать ли пути со слабыми ссылками (weak reference) или нет. По умолчанию пути со слабыми ссылками не включаются. 
    
    select heap.livepaths(s) from java.lang.String s
    Каждый элемент этого массива сам является другим массивом. Последний массив содержит объекты, которые входят в «цепочку ссылок» пути.
  • heap.roots — возвращает Enumeration корней кучи. У каждого объекта Root есть следующие свойства:
    • id — строковый id объекта, на который ссылается этот корень
    • type — описательный тип Root (JNI Global, JNI Local, Java Static и т. д.)
    • description — строковое описание Root
    • referrer — объект Thread или Class, ответственный за этот корень, или null
Примеры:
  • доступ к статическому полю 'props' класса java.lang.System 
    
    select heap.findClass("java.lang.System").statics.props
    select heap.findClass("java.lang.System").props
  • получить число полей класса java.lang.String 
    
    select heap.findClass("java.lang.String").fields.length
  • найти объект, id которого задан 
    
    select heap.findObject("0xf3800b58")
  • выбрать все классы с шаблоном имени java.net.* 
    
    select filter(heap.classes(), "/java.net./.test(it.name)")

функции для отдельных объектов

  • allocTrace(jobject)
  • classof(jobject)
  • forEachReferrer(callback, jobject)
  • identical(o1, o2)
  • objectid(jobject)
  • reachables(jobject, excludedFields)
  • referrers(jobject)
  • referees(jobject)
  • refers(jobject)
  • root(jobject)
  • sizeof(jobject)
  • rsizeof(jobject)

функция allocTrace
Возвращает трассировку места выделения данного объекта Java, если она доступна. allocTrace возвращает массив объектов кадров (frame). У каждого объекта кадра есть следующие свойства:
  • className — имя класса Java, чей метод выполняется в кадре.
  • methodName — имя метода Java, выполняющегося в кадре.
  • methodSignature — сигнатура метода Java, выполняющегося в кадре.
  • sourceFileName — имя исходного файла класса Java, выполняющегося в кадре.
  • lineNumber — номер строки исходника внутри метода.
функция classof
Возвращает объект Class данного объекта Java. Результирующий объект поддерживает следующие свойства:
  • name — имя класса.
  • superclass — объект Class для суперкласса (или null, если java.lang.Object).
  • statics — пары имя, значение для статических полей класса.
  • fields — массив объектов полей. У объектов полей есть свойства name, signature.
  • loader — объект ClassLoader, который загрузил этот класс.
У объектов Class есть следующие методы:
  • isSubclassOf — проверяет, является ли данный класс прямым или косвенным подклассом этого класса.
  • isSuperclassOf — проверяет, является ли данный Class прямым или косвенным суперклассом этого класса.
  • subclasses — возвращает массив прямых и косвенных подклассов.
  • superclasses — возвращает массив прямых и косвенных суперклассов.
Примеры:
  • показать имя класса каждого объекта типа Reference 
    
    select classof(o).name from instanceof java.lang.ref.Reference o
  • показать все подклассы java.io.InputStream 
    
    select heap.findClass("java.io.InputStream").subclasses()
  • показать все суперклассы java.io.BufferedInputStream 
    
    select heap.findClass("java.io.BufferedInputStream").superclasses()
функция forEachReferrer
вызывает функцию обратного вызова для каждого ссылающегося (referrer) данного объекта Java.
функция identical

Возвращает, идентичны ли два данных объекта Java.

Пример: 

    select identical(heap.findClass("Foo").statics.bar, heap.findClass("AnotherClass").statics.bar)
функция objectid

Возвращает строковый id данного объекта Java. Этот id можно передать в heap.findObject и также использовать для сравнения объектов на идентичность.

Пример: 

    select objectid(o) from java.lang.Object o
функция reachables

Возвращает массив объектов Java, на которые транзитивно ссылается данный объект Java. Необязательно принимает второй параметр — имена полей через запятую, которые нужно исключить из вычисления достижимости. Поля записываются в шаблоне class_name.field_name.

Примеры:
  • напечатать все достижимые объекты из каждого экземпляра Properties. 
    
    select reachables(p) from java.util.Properties p
  • напечатать все достижимые из каждого java.net.URL, но опустить объекты, достижимые через указанные поля. 
    
    select reachables(u, 'java.net.URL.handler') from java.net.URL u
функция referrers

Возвращает перечисление объектов Java, которые держат ссылку на данный объект Java.

Примеры:
  • напечатать число ссылающихся для каждого экземпляра java.lang.Object 
    
    select count(referrers(o)) from java.lang.Object o
  • напечатать ссылающихся для каждого объекта java.io.File 
    
    select referrers(f) from java.io.File f
  • напечатать объекты URL только если на них ссылаются 2 или больше 
    
    select u from java.net.URL u where count(referrers(u)) > 2
функция referees

Возвращает массив объектов Java, на которые данный объект Java напрямую ссылается.

Пример: напечатать все статические поля-ссылки класса java.io.File 

    select referees(heap.findClass("java.io.File"))
функция refers

Возвращает, ссылается ли первый объект Java на второй объект Java.

функция root

Если данный объект входит в корневое множество объектов, эта функция возвращает описательный Root object (объект Root), объясняющий почему. Если данный объект не корень, функция возвращает null.

функция sizeof
Возвращает размер данного объекта Java в байтах Пример: 

    select sizeof(o) from int[] o
функция retainedsize
Возвращает размер сохранённого множества (retained set) данного объекта Java в байтах Предупреждение! Первое использование этой функции на heap dump может занять значительное время Пример: 

    select rsizeof(o) from instanceof java.lang.HashMap o
функция toHtml
Возвращает HTML-строку для данного объекта Java. Учтите, что это вызывается автоматически для объектов, выбранных выражением select. Но это может быть полезно, чтобы печатать более сложный вывод. Пример: напечатать гиперссылку жирным шрифтом 

    select "<b>" + toHtml(o) + "</b>" from java.lang.Object o

Выбор нескольких значений

Несколько значений можно выбрать с помощью литералов объектов JavaScript или массивов.

Пример: показать имя и поток для каждого объекта потока 

    select { name: t.name? t.name.toString() : "null", thread: t } 
    from instanceof java.lang.Thread t

функции работы с array/iterator/enumeration

Эти функции принимают массив/итератор/перечисление и строку выражения [или функцию обратного вызова] на вход. Эти функции перебирают массив/итератор/перечисление и применяют выражение (или функцию) к каждому элементу. Учтите, что объекты JavaScript — ассоциативные массивы. Поэтому эти функции можно также использовать с произвольными объектами JavaScript.

  • concat(array1/enumeration1, array2/enumeration2)
  • contains(array/enumeration, expression)
  • count(array/enumeration, expression)
  • filter(array/enumeration, expression)
  • length(array/enumeration)
  • map(array/enumeration, expression)
  • max(array/enumeration, [expression])
  • min(array/enumeration, [expression])
  • sort(array/enumeration, [expression])
  • top(array/enumeration, [expression], [top])
  • sum(array/enumeration, [expression])
  • toArray(array/enumeration)
  • unique(array/enumeration, [expression])
функция concat

Объединяет два массива или перечисления (то есть возвращает составное перечисление).

функция contains

Возвращает, содержит ли данный массив/перечисление элемент, для которого истинно данное логическое выражение, указанное в коде. Вычисляемый код может ссылаться на следующие встроенные переменные.

  • it -> currently visited element
  • index -> index of the current element
  • array -> array/enumeration that is being iterated
Пример: выбрать все объекты Properties, на которые ссылается какое-то статическое поле какого-то класса. 

    select p from java.util.Properties p
    where contains(referrers(p), "classof(it).name == 'java.lang.Class'")
функция count

функция count возвращает число элементов входного массива/перечисления, которые удовлетворяют данному логическому выражению. Код логического выражения может ссылаться на следующие встроенные переменные.

  • it -> currently visited element
  • index -> index of the current element
  • array -> array/enumeration that is being iterated
Пример: напечатать число классов с конкретным шаблоном имени 

    select count(heap.classes(), "/java.io./.test(it.name)")
функция filter

функция filter возвращает массив/перечисление, которое содержит элементы входного массива/перечисления, удовлетворяющие данному логическому выражению. Код логического выражения может ссылаться на следующие встроенные переменные.

  • it -> currently visited element
  • index -> index of the current element
  • array -> array/enumeration that is being iterated
  • result -> result array/enumeration
Примеры:
  • показать все классы с шаблоном имени java.io.* 
    
    select filter(heap.classes(), "/java.io./.test(it.name)")
  • показать всех ссылающихся объекта URL, у которых ссылающийся не из пакета java.net 
    
    select filter(referrers(u), "! /java.net./.test(classof(it).name)")
    from java.net.URL u
функция length

функция length возвращает число элементов массива/перечисления.

функция map

Преобразует данный массив/перечисление, вычисляя данный код на каждом элементе. Вычисляемый код может ссылаться на следующие встроенные переменные.

  • it -> currently visited element
  • index -> index of the current element
  • array -> array/enumeration that is being iterated
  • result -> result array/enumeration

функция map возвращает массив/перечисление значений, созданных повторным вызовом кода на каждом элементе входного массива/перечисления.

Пример: показать все статические поля java.io.File с именем и значением 

    select map(heap.findClass("java.io.File").statics, "index + '=' + toHtml(it)")
функция max

возвращает максимальный элемент данного массива/перечисления. Необязательно принимает выражение кода для сравнения элементов массива. По умолчанию используется числовое сравнение. Выражение сравнения может использовать следующие встроенные переменные:

  • lhs -> left side element for comparison
  • rhs -> right side element for comparison
Примеры:
  • найти максимальную длину любого экземпляра String 
    
    select max(map(heap.objects('java.lang.String', false), 'it.count'))
  • найти экземпляр string с максимальной длиной 
    
    select max(heap.objects('java.lang.String'), 'lhs.count > rhs.count')
функция min

возвращает минимальный элемент данного массива/перечисления. Необязательно принимает выражение кода для сравнения элементов массива. По умолчанию используется числовое сравнение. Выражение сравнения может использовать следующие встроенные переменные:

  • lhs -> left side element for comparison
  • rhs -> right side element for comparison
Примеры:
  • найти минимальный размер любого экземпляра Vector 
    
    select min(map(heap.objects('java.util.Vector', false), 'it.elementData.length'))
  • найти экземпляр Vector с максимальной длиной 
    
    select min(heap.objects('java.util.Vector'), 'lhs.elementData.length < rhs.elementData.length')
функция sort

сортирует данный массив/перечисление. Необязательно принимает выражение кода для сравнения элементов массива. По умолчанию используется числовое сравнение. Выражение сравнения может использовать следующие встроенные переменные:

  • lhs -> left side element for comparison
  • rhs -> right side element for comparison
Примеры:
  • напечатать все объекты char[] в порядке размера. 
    
    select sort(heap.objects('char[]'), 'sizeof(lhs) - sizeof(rhs)')
  • напечатать все объекты char[] в порядке размера, но напечатать также размер. 
    
    select map(sort(heap.objects('char[]'), 'sizeof(lhs) - sizeof(rhs)'), '{ size: sizeof(it), obj: it }')
функция top

возвращает верхние N элементов данного массива/перечисления. Необязательно принимает выражение кода для сравнения элементов массива и число верхних элементов. По умолчанию возвращаются первые 10 элементов в порядке появления. Выражение сравнения может использовать следующие встроенные переменные:

  • lhs -> left side element for comparison
  • rhs -> right side element for comparison
Примеры:
  • напечатать 5 самых длинных строк 
    
    select top(heap.objects('java.lang.String'), 'rhs.count - lhs.count', 5)
  • напечатать 5 самых длинных строк, но напечатать также размер. 
    
    select map(top(heap.objects('java.lang.String'), 'rhs.count - lhs.count', 5), '{ length: it.count, obj: it }')
функция sum

Эта функция возвращает сумму всех элементов данного входного массива или перечисления. Необязательно принимает выражение как второй параметр. Оно используется, чтобы отобразить входные элементы перед суммированием.

Пример: вернуть сумму размеров достижимых объектов из каждого объекта Properties 

    select sum(map(reachables(p), 'sizeof(it)')) 
    from java.util.Properties p

    // or omit the map as in ...
    select sum(reachables(p), 'sizeof(it)') 
    from java.util.Properties p
функция toArray

Эта функция возвращает массив, который содержит элементы входного массива/перечисления.

функция unique

Эта функция возвращает массив/перечисление, содержащее уникальные элементы данного входного массива/перечисления

Пример: выбрать уникальные экземпляры char[], на которые ссылаются String. Учтите, что больше одного экземпляра String могут совместно использовать один и тот же char[] для содержимого. 

   // number of unique char[] instances referenced from any String
   select count(unique(map(heap.objects('java.lang.String'), 'it.value')))

   // total number of Strings
   select count(heap.objects('java.lang.String'))

Более сложные примеры

Напечатать гистограмму каждого загрузчика классов и числа классов, загруженных им


   select map(sort(map(heap.objects('java.lang.ClassLoader'), 
   '{ loader: it, count: it.classes.elementCount }'), 'rhs.count - lhs.count'),
   'toHtml(it) + "<br>"')

Приведённый выше запрос использует тот факт, что у java.lang.ClassLoader есть закрытое поле с именем classes типа java.util.Vector, а у Vector есть закрытое поле с именем elementCount — число элементов в векторе. Мы выбираем несколько значений (loader, count) с помощью литерала объекта JavaScript и функции map. Мы сортируем результат по count (то есть числу загруженных классов) с помощью функции sort с выражением сравнения.

Показать цепочку родитель–потомок для каждого экземпляра загрузчика классов

   select map(heap.objects('java.lang.ClassLoader'),
      function (it) {
         var res = '';
         while (it != null) {
            res += toHtml(it) + "->";
            it = it.parent;
         }
         res += "null";
         return res + "<br>";
      })

Учтите, что мы используем поле parent класса java.lang.ClassLoader и идём, пока parent не станет null, с помощью функции обратного вызова в вызове map.

Печать значений всех системных свойств

   select map(filter(heap.findClass('java.lang.System').props.table, 'it != null && it.key != null && it.value != null'),
            function (it) {
                var res = it.key.toString() + ' = ' + it.value.toString();
                return res;
            });

Приведённый выше запрос использует следующие факты:

  • у java.lang.System есть статическое поле с именем 'props' типа java.util.Properties.
  • у java.util.Properties есть поле 'table' типа java.util.Hashtable$Entry (это поле унаследовано от java.util.Hashtable). Это массив корзин хеш-таблицы.
  • у java.util.Hashtable$Entry есть поля 'key', 'value' и 'next'. Каждая запись указывает на следующую запись (или null) в той же корзине хеш-таблицы.
  • у класса java.lang.String есть поле 'value' типа char[].

Учтите, что этот запрос (и многие другие запросы) может быть нестабильным — потому что закрытые поля классов платформы Java могут быть изменены/удалены без какого-либо уведомления! (деталь реализации). Но использование таких запросов на пользовательских классах может быть безопасным — если пользователь контролирует классы.

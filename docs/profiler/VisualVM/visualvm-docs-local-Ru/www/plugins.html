Плагины

В VisualVM Plugins Center доступны различные plugin (плагины), включая сторонние; другие плагины можно получить отдельной загрузкой у их авторов. Плагины интеграции с IDE описаны на странице Features (возможности).

Если нужна особая возможность или поддержка конкретного инструмента, можно написать свой плагин. Это несложно: для API NetBeans Platform и VisualVM есть много сведений и примеров кода. Хорошая отправная точка — раздел Write Plugin (написать плагин).

Получить плагин

Чтобы установить плагин из VisualVM Plugins Center, выполните следующие шаги:

  1. В главном меню VisualVM выберите Tools (Инструменты) | Plugins (плагины) — откроется диалог Plugins
  2. Перейдите на вкладку Available Plugins (Доступные плагины) и выберите плагин, который хотите установить
  3. Нажмите кнопку Install (Установить), просмотрите и примите лицензию плагина и дождитесь загрузки и установки плагина

Примечание: плагины для автономных установок VisualVM можно скачать вручную со страницы Plugins Centers (центры плагинов).

Некоторые сторонние плагины нужно устанавливать из скачанного файла .nbm:

  1. В главном меню VisualVM выберите Tools (Инструменты) | Plugins (плагины) — откроется диалог Plugins
  2. Перейдите на вкладку Downloaded (Загруженные), нажмите кнопку Add Plugins... (Добавить плагины...), выберите скачанные файлы плагина .nbm и нажмите кнопку Open (Открыть)
  3. Нажмите кнопку Install (Установить), просмотрите и примите лицензию плагина и дождитесь установки плагина

Доступные плагины

Стабильные

MBeans Browser. Плагин MBeans Browser в целом даёт ту же функциональность, что и MBeans Browser в инструменте JDK (Java Development Kit, комплект разработки Java) JConsole: показывает MBeans (Managed Beans, управляемые компоненты) приложения, отображает значения, операции и уведомления. В VisualVM браузер будет дальше улучшаться, чтобы стать удобнее и лучше поддерживать новейшие возможности JMX.
Доступен в VisualVM Plugins Center

Visual GC Plugin. Интеграция инструмента Visual GC в VisualVM. Visual GC подключается к приложению и собирает и графически отображает данные о сборке мусора (GC), загрузчике классов и производительности компилятора HotSpot. См. Visual GC page (страница Visual GC) для подробностей.
Доступен в VisualVM Plugins Center

Tracer. Каркас и GUI для подробного мониторинга и анализа приложений Java. С помощью различных типов проб (probes) Tracer собирает метрики из приложения и показывает данные на временной шкале. Данные отображаются и графически, и в таблице и их можно экспортировать в обычные форматы для дальнейшей обработки во внешних инструментах.
Доступен в VisualVM Plugins Center

Threads Inspector. Плагин интегрируется со вкладкой Threads (Потоки) и позволяет анализировать трассировку стека одного или нескольких выбранных потоков напрямую, без необходимости снимать и открывать полные Thread Dump (дампы потоков). Это особенно полезно для быстрого и простого анализа различных проблем с потоками.
Доступен в VisualVM Plugins Center

BTrace Plugin. BTrace — инструмент динамической трассировки для Java. С этим плагином можно создавать, разворачивать и сохранять сценарии трассировки BTrace прямо из VisualVM. Подробности: http://kenai.com/projects/btrace.
Доступен в VisualVM Plugins Center

VisualVM Extensions. Назначение этого модуля — добавить поддержку дополнительной функциональности (новые JDK, JVM, версии HotSpot и т. д.), которую модули ядра VisualVM не поддерживали на момент выпуска VisualVM. Этот плагин всегда полезно поставить в свежую установку VisualVM.
Доступен в VisualVM Plugins Center

Security. GUI для настройки keystore, truststore, протоколов и шифров для подключений SSL/TLS в VisualVM. Использование плагина эквивалентно заданию соответствующих системных свойств javax.net.ssl.* и javax.rmi.ssl.client.*
Доступен в VisualVM Plugins Center

Buffer Monitor. Плагин для мониторинга использования прямых буферов, созданных ByteBuffer.allocateDirect, и отображённых буферов, созданных FileChannel.map. Учтите: мониторинг буферов требует, чтобы наблюдаемое приложение работало на JDK 7 начиная со сборки 36.
Доступен в VisualVM Plugins Center

Kill Application. Позволяет завершить наблюдаемое приложение, которое перестало отвечать.
Доступен в VisualVM Plugins Center

System Tray. Позволяет свернуть/восстановить работающий экземпляр VisualVM в системный лоток / из него. На Mac OS X не поддерживается (ничего не делает).
Доступен в VisualVM Plugins Center

JVM Capabilities. Добавляет на вкладку Overview (Обзор) дополнительный раздел с возможностями JVM наблюдаемого приложения.
Доступен в VisualVM Plugins Center

Java ME Profiler Snapshot Viewer. Позволяет открыть файл Profiler (профилировщика) Java ME SDK в VisualVM.
Доступен в VisualVM Plugins Center

JConsole Plugins Container. Контейнер плагинов JConsole позволяет использовать существующие плагины JConsole (например JTop) внутри VisualVM. Плагины полностью работоспособны, но мы рекомендуем перенести их в плагины VisualVM, чтобы лучше вписаться в рабочий процесс и интерфейс VisualVM и воспользоваться богатыми API VisualVM, которые дают больше источников данных с меньшей нагрузкой.
Доступен в VisualVM Plugins Center

В разработке

Startup Profiler. Startup Profiler позволяет профилировать запуск локальных приложений Java 5+ и помогает профилировать короткоживущие процессы. Подробности на Startup Profiler plugin page (страница плагина Startup Profiler).
Доступен в VisualVM Plugins Center

GlassFish Plugin. Плагин GlassFish даёт дополнительные сведения для серверов GlassFish: число активных сеансов, обработанных транзакций и т. д. Он также умеет мониторить каждое развёрнутое веб-приложение отдельно.
Доступен в VisualVM Plugins Center

OQL Syntax Support. Этот плагин устанавливает улучшенный редактор для консоли OQL (Object Query Language, язык запросов к объектам) в HeapWalker с подсветкой синтаксиса и базовым автодополнением кода.
Доступен в VisualVM Plugins Center

Сторонние

TDA Plugin. Thread Dump Analyzer (TDA) для Java — небольшой GUI для анализа дампов потоков и сведений о куче, которые генерирует Sun Java VM. Он даёт статистику по дампам потоков, сведения о заблокированных мониторах и ожидающих потоках и многое другое. Подробное описание: http://java.net/projects/tda.
Доступен в VisualVM Plugins Center

OSGi Plugin. Плагин для базового управления платформами OSGi через JMX. Подробное описание и инструкции по установке — на plugin page (странице плагина).
Доступен в VisualVM Plugins Center

CRaSH Plugin. Плагин для поддержки открытой оболочки CRaSH для платформы Java в VisualVM. Подробное описание и инструкции по установке — на plugin page (странице плагина).
Доступен в Plugins Center поставщика

Coherence Plugin. Плагин Coherence позволяет разработчикам смотреть сводную статистику и сведения при подключении к кластеру Coherence с включённым JMX. Подробное описание и инструкции по установке — на plugin page (странице плагина).
Доступен на странице плагина поставщика

Написать плагин

Для разработчиков плагинов VisualVM сейчас доступны такие ресурсы:

  • Developer Documentation (документация для разработчиков)
  • Sources (исходный код)
  • Build Guide (руководство по сборке)
  • Sample Projects (примеры проектов)
  • API Documentation (документация API)

Много сведений и примеров плагинов VisualVM есть в Geertjan's Blog (блог Гертьяна Виленги). Вопросы можно задавать и получать помощь в списке рассылки users@visualvm.java.net (чтобы пользоваться списком рассылки, нужно зарегистрироваться).

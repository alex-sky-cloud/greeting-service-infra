Eclipse launcher для VisualVM

Eclipse launcher для VisualVM — это plugin (плагин) Eclipse, который делает мониторинг и профилирование проектов Eclipse с помощью VisualVM удобнее для пользователей IDE. Он запускает VisualVM вместе с наблюдаемым приложением и после старта VisualVM автоматически открывает вкладку приложения.

Примечание: Eclipse launcher для VisualVM поддерживает VisualVM 1.1 и новее; со старыми выпусками инструмента он работает некорректно.

Установка

  • Eclipse 3.6+
    1. Распакуйте архив в каталог по вашему выбору
    2. Добавьте локальный update site, указывающий на выбранный каталог
    3. Установите VisualVM Launcher Feature
  • Eclipse 3.5
    1. Распакуйте архив в каталог установки Eclipse

Настройка

Перейдите в Run/Debug-Launching-VisualVM Configuration (Запуск/Отладка — Запуск — Конфигурация VisualVM) preferences section (раздел параметров)
Здесь можно изменить:

  • JDK Home, который будет использовать VisualVM (нужен JDK (Java Development Kit, комплект разработки Java), а не JRE)
  • Путь к исполняемому файлу VisualVM (поддерживается VisualVM 1.1+)

Использование

  1. Создайте новую application configuration (конфигурацию приложения)
  2. Выберите "VisualVM Launcher" как application launcher (запускатель приложения)
  3. Запустите или отладьте приложение с созданной конфигурацией — VisualVM запустится автоматически

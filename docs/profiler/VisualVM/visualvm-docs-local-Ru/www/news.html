6 мая 2008 г.: выпущена VisualVM 1.0 RC. Это в основном стабилизирующий выпуск: исправлено много ошибок, существенно улучшены производительность и управление памятью. Единственная новая возможность — Start Page (стартовая страница) со полезными ссылками на документацию VisualVM и руководства JDK по мониторингу и устранению неполадок. Исходный код этого выпуска доступен в ветке release10.

14 апреля 2008 г.: выпущена VisualVM Beta 2. Улучшены снимки приложений (Application Snapshots) (вкладку Overview (Обзор) теперь можно сохранять), сделано много мелких улучшений. API и код приведены в порядок, исправлено несколько серьёзных ошибок. Исходный код этого выпуска доступен в ветке visualvm_beta2.

7 марта 2008 г.: выпущена VisualVM Beta. В этом выпуске много новых возможностей: приложения, заданные подключением JMX, снимки приложений, сохранение определённых узлов и дампов ядра ВМ, Load и Save As для дампов потоков и дампов кучи, автообнаружение jstatd, запущенного после определения удалённого узла, улучшенная поддержка ВМ JRockit, новые значки, упорядочивание главного меню и панели инструментов, настраиваемые Options (Параметры), плагин GlassFish в Plugin Center. Исходный код доступен в ветке visualvm_beta.

19 февраля 2008 г.: выпущена VisualVM Milestone 3. Это в основном выпуск с исправлениями ошибок и стабилизацией с некоторыми мелкими улучшениями; самое существенное изменение — приведение API в порядок. Исходный код этого выпуска доступен в ветке visualvm_m3.

15 февраля 2008 г.: исходный код VisualVM доступен в SVN. Имейте в виду, что экспериментальный API VisualVM всё ещё активно разрабатывается. Краткие инструкции по сборке доступны здесь.

7 февраля 2008 г.: выпущена VisualVM Milestone 2. Для этого выпуска определён экспериментальный API, позволяющий плавно интегрировать сторонние плагины в интерфейс и рабочий процесс VisualVM. Этот API и исходный код будут опубликованы в ближайшее время. Другие новости Milestone 2: отдельное представление потоков для каждого приложения, поддержка дампов ядра на Linux и Solaris (обзор, снятие дампа потоков и кучи), объединены несколько исправлений из профилировщика NetBeans. Из Plugin Center можно загрузить MBean Browser с улучшенным интерфейсом, обёртку для плагинов JConsole и инструмент VisualGC.

15 января 2008 г.: выпущена VisualVM Milestone 1. Основные изменения в этом выпуске: улучшенный интерфейс, лучшая поддержка виртуальных машин Sun и BEA, простой просмотрщик localhost, распознавание некоторых приложений (Ant, Tomcat, GlassFish/SJSAS, JBoss, NetBeans и др.).

19 ноября 2007 г.: выпущена VisualVM Preview 2. В этом выпуске представлен Plugin Center — репозиторий, откуда можно получать расширения VisualVM (сейчас доступны MBean browser и VisualGC). Другие новости: новый диалог About (О программе), последние исправления профилировщика, последняя платформа NetBeans, улучшения удобства использования.

15 октября 2007 г.: выпущена VisualVM Preview 1. Она предоставляет базовые возможности мониторинга и профилирования как в производственной среде, так и при разработке.

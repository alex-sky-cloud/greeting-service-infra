Примечания к выпуску VisualVM 1.1

VisualVM — визуальный инструмент, объединяющий несколько командных утилит JDK и лёгкие возможности профилирования. Предназначен как для производственной среды, так и для разработки; он расширяет возможности мониторинга и анализа производительности платформы Java SE.

Выпуск VisualVM 1.1 основан на VisualVM 1.0.1. Список изменений и исправлений с момента VisualVM 1.0.1 см. в разделе Изменения в 1.1. Подробный обзор всех выпусков VisualVM и Java VisualVM см. на странице Обзор выпусков.

Системные требования

Поддерживаемые ОС:

  • Microsoft Windows (XP, Vista, Server): 32bit & 64bit
  • Linux: платформа Intel, 32bit & 64bit
  • Sun Solaris: платформы Intel и Sparc, 32bit & 64bit
  • Mac OS X: платформа Intel, 64bit

Экспериментальная поддержка:

  • HP-UX 11i: платформа PA-RISC, 32bit & 64bit

Требуемое ПО: Sun JDK 6+, OpenJDK 6+, IcedTea 6+, Apple JDK 6+
Экспериментальная поддержка: HP-UX JDK 6.0.01+

Изменения в 1.1

Возможности и улучшения:

  • График использования CPU и активности GC на вкладке Monitor
  • Табличное представление на вкладке Threads
  • Параметры командной строки: --openpid (открыть PID), --openjmx (открыть JMX), --openfile (открыть файл)
  • Действие Compare Memory Snapshots в контекстном меню
  • Кнопки Copy To Clipboard / Save To File в диалоге About
  • Мониторинг IBM JVM через подключение JMX
  • Экспериментальная поддержка HP-UX PA-RISC
  • Плагин интеграции для Eclipse IDE
  • В качестве основы — NetBeans Platform 6.5

Изменения API:

  • Совместимо: com.sun.tools.visualvm.host.HostsSupport.createHost(hostname, displayname) добавлено
  • Совместимо: com.sun.tools.visualvm.jmx.application.JmxApplicationsSupport добавлено
  • Совместимо: com.sun.tools.visualvm.application.jvm.Jvm.isCpuMonitoringSupported() и isCollectionTimeSupported() добавлено
  • Совместимо: com.sun.tools.visualvm.application.jvm.MonitoredData.getProcessCpuTime() и getCollectionTime() добавлено
  • Несовместимо: com.sun.tools.visualvm.host.model.HostOverviewFactory сделан final
  • Несовместимо: com.sun.tools.visualvm.core.datasource.descriptor.DataSourceDescriptor.<init>() удалено
  • Несовместимо: com.sun.tools.visualvm.coredump.CoreDumpSupport.register() больше не является public
  • Несовместимо: com.sun.tools.visualvm.host.HostsSupport.getStorageDirectoryString() и getHostProvider() больше не являются public

Исправленные ошибки: запросом Issue Tracker.

Известные проблемы

  • Issue 224: Не удаётся профилировать память JBoss AS 4.2.3.GA
  • Issue 148: VisualVM зависает при потере удалённого соединения
  • Issue 120: Источник данных приложения JMX нельзя повторно использовать после перезапуска приложения
  • Issue 72: Запущенное приложение иногда не распознаётся

Чтобы просмотреть все известные проблемы, воспользуйтесь этим запросом Issue Tracker.


История изменений

Изменения в 1.0.1

Возможности и улучшения:

  • Профилировщик поддерживает OpenJDK
  • Профилировщик незаметно отключается на неподдерживаемых платформах, остальная часть инструмента работает без изменений
  • Небольшие улучшения предупреждающих сообщений в инструменте и плагинах, чтобы лучше описывать обнаруженные проблемы
  • Новые плагины в центре плагинов: JvmCapabilities, KillApplication, SysTray

Исправленные ошибки: запросом Issue Tracker.

# Как открыть документацию VisualVM

В архиве лежит копия документации. Распакуйте zip в любую папку. Дальше нужен только браузер.

Ниже не три обязательных шага подряд, а **один выбор**: как вам удобнее открыть. Достаточно одного способа.

---

## Зачем вообще несколько способов

Документация на сайте сделана так: сверху шапка VisualVM, а сами статьи с картинками живут **внутри рамки**.

Когда вы открываете файл двойным щелчком, браузер показывает его как `file://...`. В этом режиме рамка часто **не рисует картинки**, хотя файлы картинок на диске есть. Поэтому:

- если открыть «как файл» — лучше заходить сразу в статьи, без рамки;
- если нужна страница **один в один как на сайте** (шапка + статьи + картинки) — сначала запускается крошечный локальный сервер, и браузер открывает `http://127.0.0.1:8765/...`. Для него это уже обычный сайт, картинки показываются.

Выберите **один** вариант ниже.

---

## Вариант А. Самый простой: просто файлы

Подходит, если нужны статьи и снимки экрана и не важна верхняя шапка сайта.

1. Распакуйте архив.
2. Зайдите в папку `visualvm-docs-local`, затем в `www`.
3. Откройте двойным щелчком `docindex.html` — это оглавление.
4. Дальше ходите по ссылкам, как по обычному сайту. Картинки должны быть на месте.

Можно сразу открыть нужную статью, например `www/gettingstarted.html`.

---

## Вариант Б. Как на сайте: шапка, рамка, картинки

Подходит, если хотите ту же страницу, что https://visualvm.github.io/documentation.html.

1. Распакуйте архив.
2. В папке `visualvm-docs-local` дважды щёлкните `start.bat`.
3. Откроется браузер по адресу http://127.0.0.1:8765/documentation.html
4. Окно чёрной консоли **не закрывайте**, пока читаете документацию. Это и есть локальный сервер. Закроете — страница перестанет открываться.

Windows сам умеет так раздавать файлы (PowerShell). Python ставить не нужно.

На Linux или macOS вместо `start.bat` запустите `start.sh` (нужен Python 3).

---

## Что будет, если открыть documentation.html двойным щелчком

Файл `documentation.html` — это оболочка сайта с рамкой. Через `file://` картинки в рамке обычно пропадают.

Поэтому при таком открытии страница **сама перейдёт** на `www/docindex.html` (вариант А). Это не поломка, так и задумано: чтобы вы увидели картинки, а не пустые рамки.

Если нужна именно оболочка с шапкой — используйте вариант Б (`start.bat`).

---

## Что лежит в архиве

| Файл или папка | Зачем |
|----------------|--------|
| `www/docindex.html` | Оглавление документации |
| `www/` | Статьи, снимки экрана, значки, API |
| `documentation.html` | Оболочка как на сайте (нужен вариант Б) |
| `start.bat` | Запуск локального сервера в Windows |
| `start-server.ps1` | Сам сервер, его вызывает `start.bat` |
| `start.sh` | То же для Linux и macOS |
| `README.md` | Эта памятка |

Интернет нужен только для ссылок наружу: GitHub, документация Java SE, ролики YouTube. Сами руководства и картинки читаются с диска.

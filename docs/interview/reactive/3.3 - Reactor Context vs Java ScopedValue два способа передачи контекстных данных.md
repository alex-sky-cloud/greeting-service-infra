## 1. Что такое ScopedValue

`ScopedValue` — механизм в Java (preview начиная с Java 20-21), задуманный как безопасная замена `ThreadLocal` специально для виртуальных потоков (Virtual Threads, Project Loom). Он позволяет привязать неизменяемое значение к текущему потоку выполнения на время работы конкретного блока кода через `ScopedValue.where(...).run(...)`, и это значение автоматически корректно наследуется дочерними виртуальными потоками — в отличие от обычного `ThreadLocal`.

## 2. Ключевое отличие от Reactor Context

- `ScopedValue` — решение на уровне **потока** (thread-based): работает, когда используется блокирующий, синхронный стиль кода на виртуальных потоках, где один логический запрос обрабатывается одним потоком на всём протяжении.
- Reactor `Context` — решение на уровне **подписки** (subscription-based): не зависит от потока вообще, потому что в реактивной модели один логический запрос может исполняться на десятках разных потоков по очереди через `subscribeOn`/`publishOn`.

## 3. Сравнительная таблица

| Критерий | Reactor Context | Java ScopedValue |
|---|---|---|
| Привязка | К цепочке подписки (Subscriber) | К текущему потоку выполнения |
| Совместимость с переключением потоков | Полная — переживает subscribeOn/publishOn | Не применим напрямую при переключении потоков |
| Целевая платформа | Реактивный стек (Project Reactor, WebFlux) | Виртуальные потоки (Project Loom), блокирующий стиль |
| Изменяемость | Неизменяемый (immutable), новый Context на каждую запись | Неизменяемое значение на время выполнения блока |
| Наследование дочерними задачами | Через явную передачу вдоль цепочки операторов | Автоматическое наследование дочерними виртуальными потоками |

## 4. Практический вывод

При переходе с реактивного стека (WebFlux + Reactor) на виртуальные потоки `ScopedValue` становится аналогом `Context` — но эти два механизма несовместимы напрямую. Оба решают одну и ту же задачу — передачу контекстных данных без потери при асинхронности/конкурентности — но принципиально разными способами: один привязкой к потоку, другой привязкой к цепочке подписки.

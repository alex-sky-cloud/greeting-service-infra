# Локальная документация VisualVM

Копия страницы https://visualvm.github.io/documentation.html и полного комплекта статей, который она встраивает (архив visualvm.java.net).

## Как открыть

Распакуйте архив. Откройте в браузере файл `documentation.html` (двойной щелчок или «Файл → Открыть»).

В рамке будет оглавление. Все внутренние ссылки и картинки открываются с диска, интернет не нужен.

Можно сразу открыть `www/docindex.html` — это то же оглавление без шапки сайта.

## Что внутри

- `documentation.html` — та же оболочка, что на сайте, iframe смотрит на локальный `www/docindex.html`
- `www/` — статьи, руководства, снимки экрана, API
- `css/`, `images/`, `js/` — оформление шапки сайта

Внешние ссылки (GitHub, Stack Overflow, документация Java SE) по-прежнему ведут в сеть. Остальное работает офлайн.

Источник документации: репозиторий visualvm/visualvm.java.net.backup, каталог www, ветка master.
